# COR

The COR plugin connects Cursor to a COR workspace. From the agent you can work with projects, tasks, messages, and time logs.

The plugin uses the COR MCP server at `https://mcp.projectcor.com/mcp`. On first use, Cursor signs you in with your existing COR account through OAuth. Your COR role still limits what the agent can do.

## Install the plugin

Use these steps after COR is listed in the Cursor Marketplace.

1. Open **Customize** in the Cursor sidebar.
2. Find COR.
3. Select **Install**.
4. Choose a project scope or a user scope.
5. When Cursor opens a browser window, sign in with your COR account and approve access.

[projectcor.com](https://projectcor.com) is the product site. The [COR MCP server](https://developers.projectcor.com/ai-tools/mcp-server) page documents the server.
