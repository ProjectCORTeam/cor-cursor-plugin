# Changelog

All notable changes to this plugin will be documented here.

## 1.1.0 — skills

- Added `log-hours-from-commits`, `work-from-cor-task`, `project-status-report`, and `triage-pending-tasks`.
- Set `skills` to `./skills/` and bumped the plugin to 1.1.0.

## 1.0.0 — initial release

- Added the `cor` MCP server pointing at `https://mcp.projectcor.com/mcp`.
- Auth uses OAuth with the signed-in COR account.
- Logo is COR's official isologo on a white plate.
